# IPL Match Prediction

A machine learning project to predict the win probability of the chasing team in an IPL match. The model uses historical data and real-time match variables to calculate outcomes.

## Project Description
The goal of this project is to analyze the factors that influence the outcome of an IPL match. It focuses on variables like venue, batting team, bowling team, wickets fallen, and required run rate.

## Technical Details
- Data Source: IPL.csv from kaggle
- Model Used: Logistic Regression 
- Features: Batting Team, Bowling Team, City, Runs Left, Balls Left, Wickets Left, Target, CRR, RRR.


## Accuracy
The model currently achieves an accuracy of 81.33% on the test dataset.
